# SITE DE VENDA DO EBOOK

## Arquivos
- index.html = página principal
- checkout.html = página de checkout visual
- obrigado.html = página de agradecimento
- style.css = design do site

## CONFIGURAÇÕES IMPORTANTES

### 1. WhatsApp
Em todos os arquivos HTML, procure:
5511999999999

Troque pelo seu número no formato:
55 + DDD + número
Exemplo:
5511987654321

### 2. Checkout real
Abra checkout.html e procure:
https://SEU-LINK-DE-PAGAMENTO-AQUI.com

Troque pelo link do checkout gerado pela sua plataforma de pagamento.

Você pode usar, por exemplo, Hotmart, Kiwify, Eduzz, Stripe ou outra plataforma compatível.

### 3. Formulário de contato
O formulário atual é visual. Para receber mensagens reais, conecte-o a um serviço de formulários ou a um backend.
Exemplos de opções: Formspree, Netlify Forms ou um servidor próprio.

### 4. Página de obrigado
Na plataforma de pagamento, quando disponível, configure a página de retorno/sucesso:
obrigado.html

## PUBLICAÇÃO
1. Renomeie/organize os arquivos mantendo todos juntos.
2. Envie todos os arquivos para a hospedagem.
3. O arquivo index.html deve ficar na pasta principal do site, geralmente public_html.
4. Teste no celular.
5. Teste o botão do WhatsApp.
6. Teste o checkout antes de divulgar.

IMPORTANTE: não coloque o PDF diretamente em uma URL pública se quiser controlar a distribuição. Use a entrega digital da sua plataforma de pagamento quando possível.
